Política de Privacidade — Negi

ATENÇÃO: Ao utilizar o bot Negi, você concorda com 
esta política de privacidade.

**Sobre o bot**

A Negi é um bot feito com intuito de comandos para diversão e utilidades pro discord.

Dados coletados a bot pode coletar e armazenar as seguintes informações:

- ID do usuário
- ID do servidor
- Dados de XP e economia
- Configurações do servidor
- Mensagens (apenas quando necessário para comandos)

Uso dos dados Os dados são utilizados exclusivamente para:

- Funcionamento dos comandos do bot

- Sistema de XP e economia
Mensagens automáticas (welcome/saída)

- Funcionalidades internas do bot

- Os dados não são compartilhados com terceiros.

Intents utilizadas O bot utiliza as seguintes intents do Discord:

- MESSAGE CONTENT → para leitura de comandos e sistemas de XP

- MEMBERS → para sistema de entrada/saída e contagem de membros

Armazenamento 

Os dados são armazenados localmente em banco de dados SQLite e utilizados apenas para o funcionamento do bot.
